# Vyxa LLM 
 
Vyxa is an **open-source large language model (LLM)** optimized for **Web3 developers, AI researchers, and decentralized applications**. It supports **smart contract auditing, blockchain analytics, and DeFi automation**.  

---

## ⚡ Quick Start - Run Vyxa with Ollama  

Vyxa is available via **Ollama**, making it easy to run locally with minimal setup.  

### **🔹 Step 1: Install Ollama**  
Ollama is required to run Vyxa. Install it using the following commands:  

#### **🔸 macOS & Linux**  
```bash
curl -fsSL https://ollama.com/install.sh | sh
```
